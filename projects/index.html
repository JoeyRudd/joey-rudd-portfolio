JR.2026.01 / Ontario Science Centre

Extrema Buddies

Virtual pet game. Godot 4.7, GDScript. 2026.

A virtual pet game where you adopt an extremophile, a Pompeii worm or a brine shrimp, and keep it alive while learning how real organisms survive extreme places.

It's the biggest codebase I've owned, so I spent as much time on architecture, tests and documentation as on gameplay.

My roleLead developer. I wrote most of the code (850+ commits), designed how each species is structured, and documented it so the next developer can add a creature from a checklist.
Built withGodot 4.7, GDScript, GUT (testing), web export, CSV-based localization
SkillsState machines, 2D physics and object pooling, save systems, test-driven fixes, English and French localization
Outcomes
  • 100+ automated tests covering game logic, saves and French layouts.
  • Two playable species shipped as English and French web builds for mobile portrait play.
  • A physics-based salinity minigame that switches to batched rendering when hundreds of salt particles are on screen.
Source code is private (Ontario Science Centre)

JR.2026.02 / Ontario Science Centre

Science Bonds

Touchscreen word-matching game. React, Node.js, SQLite. 2026.

A word-grouping puzzle for an Ontario Power Generation event. Visitors find four groups of science words before they run out of lives or time.

It had to survive a full day of walk-up play on a kiosk with nobody watching it.

My roleSole developer. I built the game, the CSV content pipeline and the local telemetry server, and set it up on-site.
Built withReact 18, Vite, Motion, Node.js, SQLite, PapaParse
SkillsTouch-first UI, component design, small backend APIs, privacy-friendly telemetry, kiosk hardening
Outcomes
  • Ran live at the Ontario Power Generation event.
  • Puzzle boards load from CSV, so science educators write new content without touching code.
  • Session data (outcome, time taken, groups found) stays on the kiosk and shows how people actually play.
Source code is private (Ontario Science Centre)

JR.2026.03 / Ontario Science Centre

Human Body Atlas

3D anatomy explorer. Three.js, JavaScript. 2026.

A 3D model of the human body in the browser. You switch between five body systems and tap touchpoints to learn what each organ does.

The hard part was making a detailed model load quickly and stay usable for people who can't use a mouse.

My roleSole developer. I built the scene, model loading, interaction and content data from scratch.
Built withThree.js, JavaScript, glTF with Meshopt compression, Tween.js, Vite
Skills3D scene setup, asset compression, camera animation, keyboard accessibility
Outcomes
  • Five systems (skeletal, digestive, cardiovascular, respiratory, nervous) with animated transitions.
  • Full keyboard navigation alongside touch and mouse.
  • Systems and touchpoints are data-driven, so new content is a config change.
Source code is private (Ontario Science Centre)

JR.2025.01 / Personal project

Hypertrofit

AI fitness and nutrition coach. Python, FastAPI, Vue. 2025.

A fitness coach you can talk to. I wanted it to feel like a conversation, not a form with extra steps.

The challenge was stopping the AI from making things up, which is what led me to retrieval-augmented generation (RAG).

My roleSolo developer. I designed it and built the frontend, API, retrieval pipeline, tests and deployment.
Built withPython, FastAPI, Vue 3, Docker, GitHub Actions, Railway, Netlify
SkillsFull-stack development, RAG and search ranking, API design, automated testing, CI/CD
Outcomes
  • Answers are grounded in 800+ chunks of real fitness content.
  • 100/100 Lighthouse performance with automatic deploys.
  • A 57-test suite runs on every push.
